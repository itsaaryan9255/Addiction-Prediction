# 🧠 Addiction Prediction using Machine Learning

## 📌 Project Overview

The **Addiction Prediction using Machine Learning** project aims to predict the likelihood of an individual developing an addiction (such as substance use, internet addiction, gaming addiction, etc.) based on behavioral, psychological, and demographic factors.
This system helps in **early detection and prevention**, enabling timely intervention by healthcare professionals, counselors, or guardians.

---

## 🎯 Objectives

* Predict addiction risk using ML algorithms
* Analyze factors contributing to addictive behavior
* Provide insights for prevention and awareness
* Build a user-friendly prediction system

---

## 🗂️ Dataset

The dataset includes features such as:

* Age
* Gender
* Daily screen time
* Sleep hours
* Stress level
* Social interaction level
* Academic/work performance
* Family history of addiction
* Substance usage frequency

*(Dataset can be collected via surveys, public datasets, or simulated data.)*

* Logistic Regression
